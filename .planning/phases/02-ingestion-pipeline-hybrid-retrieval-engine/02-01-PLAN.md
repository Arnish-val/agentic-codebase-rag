# Plan 02-01: Multi-Format Document Parsers & Hierarchical Chunking

## Objective
Build multi-format document parsers and hierarchical chunking engines (code, markdown, openapi) that maintain parent-child relationships, exact line ranges, and AST metadata.

## Tasks

### Task 1: AST Code Chunker
Implement `codeChunker.js` to extract functions, classes, methods, and blocks with startLine/endLine location tags.

### Task 2: Section-based Markdown & OpenAPI Chunkers
Implement `markdownChunker.js` and `openapiChunker.js` for structured doc indexing.

### Task 3: Chunker Factory Integration
Wire `factory.js` to dispatch to language-specific chunkers based on file extension.
